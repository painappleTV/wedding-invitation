# ゲスト一括登録用 CSV フォーマット

DynamoDB にゲストを一括投入するときの CSV の形式です。

## 文字コード

- **UTF-8（BOM 付き推奨）**  
  Excel で編集する場合は「UTF-8 BOM 付き」で保存すると文字化けしません。

## 1行目：ヘッダー（必須）

次の列名を **1行目** に書きます。順番はこのとおりにしてください。

| 列名 | 必須 | 説明 |
|------|------|------|
| `inviteCode` | 任意 | 招待コード。空欄なら自動生成（英数字）。指定すればそのコードで登録。 |
| `name` | 必須 | 世帯名・表示名（例：山田家、佐藤花子） |
| `message` | 必須 | 招待状に表示するメッセージ。カンマや改行を含む場合は `"..."` で囲む。 |
| `guestType` | 任意 | `親族` または `友人`。集合時間の出し分けに使います。空欄可。 |
| `members` | 任意 | 招待メンバーが複数いる場合、**セミコロン `;` 区切り**で列挙（例：`山田太郎;山田花子`）。1名のみ・世帯名のみの場合は空欄でよい。 |

## 2行目以降：データ

- 1行 = 1ゲスト（1招待先）。
- カンマを含むセルは **ダブルクォート `"` で囲む**（例：`"こんにちは、よろしく"`）。
- セル内に `"` を書きたい場合は `""` とエスケープ（例：`"彼は""OK""と言った"`）。

## サンプル

```csv
inviteCode,name,message,guestType,members
,山田家,"いつもお世話になっております。ぜひお越しください。",親族,"山田太郎;山田花子;山田一郎"
,佐藤家,"お二人の門出を心よりお祝い申し上げます。",友人,"佐藤花子;佐藤健一"
mycode,鈴木一郎,"この度はお招きいただきありがとうございます。",友人,
```

- 1件目: inviteCode は空 → 自動生成。親族、メンバー3名。
- 2件目: inviteCode は空 → 自動生成。友人、メンバー2名。
- 3件目: inviteCode に `mycode` を指定。友人、メンバーなし（世帯名のみ）。

## 投入コマンド

CSV を用意したあと、以下で投入します。

```bash
cd scripts
npm install
npx tsx seed-from-csv.ts guests.csv
```

環境変数 `TABLE_NAME`（省略時は `wedding-guests`）・`AWS_REGION` が本番の DynamoDB を指していることを確認してください。
